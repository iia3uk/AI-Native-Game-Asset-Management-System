# Contribute to Asset Viewer

Install with `npm ci` on Node.js 22.16 or later. Run `npm run check` and `npm test` before submitting changes. Use the procedural fixture generator for public and automated reproduction steps.

Review [STATUS.md](docs/STATUS.md) and [ARCHITECTURE.md](docs/ARCHITECTURE.md) before changing a subsystem. Keep the core usable outside the renderer. Preserve compatibility with existing user data and verify the affected browser workflow or packaged build.

Use the issue and pull request templates. Omit credentials, local data, paths and private assets from uploads.

MIT is a proposed project license. The repository owner must approve licensing before a license is added or third-party contributions are distributed under it.
